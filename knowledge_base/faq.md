# AI Support Ticket Copilot - Sample Support FAQ

## Account Login and Password Reset
If a customer cannot log in, confirm that they are using the correct email.
Ask them to use the Forgot Password option and check their email inbox
and spam folder. They should never share their password or verification code.

If the customer has reset the password but still cannot log in,
ask them to describe the exact error. Escalate persistent login problems
to the human support team.

## Billing and Payments
If a payment appears to have failed, ask the customer to check their
bank or payment provider for the transaction status.
Do not ask them to share full card numbers, CVV, or banking passwords.

If a payment was deducted but the account does not show the purchase,
collect the transaction reference if available and escalate for review.

## Refund Requests
A refund request must be reviewed by the human support team.
The AI assistant must not promise that a refund has been approved
or that money has already been returned.
Ask for the order or transaction reference without requesting sensitive
payment credentials.

## Technical Problems
For an application error, ask the customer to restart the application,
check their internet connection, and try again.
For browser-related issues, suggest refreshing the page or trying another
supported browser.

If the problem persists, collect the error message and steps to reproduce
the issue, then route it to technical support.

## Security and Account Compromise
If a customer reports suspicious account activity or possible account
compromise, classify the issue as high priority and escalate it
to a human support agent.
Never request passwords, one-time passcodes, or recovery codes.
Do not claim that an account has been secured unless that action
has actually been performed by an authorized system.

## General Support
If a question is not covered by this FAQ, be transparent that the available
documentation does not provide a confirmed answer.
Draft a helpful response and recommend human support when needed.
